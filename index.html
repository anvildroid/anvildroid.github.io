Android apps, at home on your Linux desktop.

AnvilDroid is a desktop app and runtime controller for Waydroid. Run several isolated Android devices side by side and open every app in its own native window, on Wayland and X11.

Everything you need to live with Android apps on Linux

Waydroid runs the Android system. AnvilDroid handles the rest: windows, settings, input and updates.

Isolated devices

Run several Android devices side by side. Each one has its own apps, data and storage location, plus RAM and CPU limits.

Native app windows

Every Android app opens as its own desktop window on Wayland and X11. You can still switch a device to the full Android UI.

Desktop notifications

Android notifications appear in your desktop's notification center. You choose which apps can show them.

Game controls

Map mouse and keyboard to touch, capture the mouse for FPS games, and record macros. Schemes are saved per app; press F2 in a game window.

Fits into your desktop

Type with your host input method (e.g. Fcitx), share the clipboard, and open host folders from inside Android.

Images and compatibility

Use official or custom images (ext4, EROFS, SquashFS). ARM translation, device identity profiles and help with Google Play registration are built in.

Camera and GPU

Pass one or more host webcams through to Android. Pick the GPU per device: Intel and AMD with Mesa are supported, NVIDIA is experimental.

Updates built in

Check for and install updates from Settings → Updates. If you installed from a package repository, your normal system update also updates AnvilDroid.

Your look, your tools

Pick the Classic or HUD theme, light or dark, and one of six accent colours. Developers can connect Android Studio over ADB and export diagnostics.

Install

Choose your distribution and paste one command into a terminal. It adds a signed package repository, so your normal system update also updates AnvilDroid.

curl -fsSL https://anvildroid.github.io/packages/install.sh | sudo bash

Updates come with sudo apt upgrade.

curl -fsSL https://anvildroid.github.io/packages/install-fedora.sh | sudo bash

Updates come with sudo dnf upgrade.

curl -fsSL https://anvildroid.github.io/packages/install-opensuse.sh | sudo bash

Updates come with sudo zypper update.

curl -fsSL https://anvildroid.github.io/packages/install-arch.sh | sudo bash

Updates come with sudo pacman -Syu.

Works on any distribution. Download the AppImage, make it executable, then run it:

chmod +x AnvilDroid-*-x86_64.AppImage && ./AnvilDroid-*-x86_64.AppImage

The first launch asks for administrator approval to install the runtime controller. After that, the app updates itself from Settings → Updates.

Download the AppImage

Prefer single files? Every release also includes .deb, .rpm and .pkg.tar.zst packages and a SHA256SUMS file. The install scripts are short and you can read them first, e.g. install.sh.

Requirements

  • Linux x86_64 with a Wayland or X11 desktop, glibc 2.39 or newer (Ubuntu 24.04 or later)
  • Waydroid. AnvilDroid can install the runtime tools for you.
  • Intel or AMD GPU with Mesa. NVIDIA support is experimental.
  • systemd and polkit

Get started in four steps

The app guides you through it. The user guide covers every page in detail.

  1. Open AnvilDroid from your applications menu.
  2. Download Android from the Get started guide on the Apps page. It fetches and verifies the official image (about 1 GB).
  3. Create and start your device. The first start takes a few minutes while the image is prepared.
  4. Install APK or open an app. Each app opens in its own window.

Good to know

Is AnvilDroid an emulator?

No. Like Waydroid, AnvilDroid runs a full Android system in a Linux container that shares your kernel. It is not a virtual machine, so apps run at near-native speed. AnvilDroid manages the containers and turns app windows into desktop windows.

Which Android images work best?

The official Android 13 Waydroid images are the most tested. Newer and custom images are experimental.

Will banking apps or Netflix work?

Usually not. Apps that require Play Integrity, such as banking apps, some games and DRM-protected video, generally refuse to run. Other apps depend on the image, the ARM translator and your GPU.

Why does it need administrator access?

Android devices need kernel features (binder, namespaces, mounts) that only root can set up. A small controller service runs as root and starts only when needed. The desktop app itself runs as your user.

Can I use the full Android UI and app windows together?

Not on the same device. Each device uses one mode at a time, and you can switch between them in its settings under Display.

How do I uninstall?

Remove the package with your package manager, for example sudo apt remove anvildroid-controller. For the AppImage, delete the file.
